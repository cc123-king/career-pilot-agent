# CareerPilot Agent 面试讲解手册

## 30 秒介绍

CareerPilot Agent 是一个基于 LangGraph 的多智能体求职助手。用户输入简历和招聘 JD 后，系统依次进行简历解析、岗位解析、本地知识检索、人岗匹配、简历优化和模拟面试。核心特点是工作流明确、输出结构化、评分可解释，而且没有 API Key 时也能通过规则和轻量检索完成完整演示。

## 为什么使用 LangGraph

因为这个任务不是一次简单问答，而是有多个依赖步骤：只有先拿到简历画像和岗位画像，才能检索相关知识并计算匹配；完成匹配后才能生成有针对性的建议和面试题。LangGraph 可以把状态、节点和条件分支显式表达出来，比把所有要求写进一个超长提示词更容易调试、测试和扩展。

## 状态中保存什么

`CareerState` 保存原始简历、原始 JD、`ResumeProfile`、`JobProfile`、`MatchReport`、建议、面试题、RAG 引用、执行轨迹和警告信息。节点读取自己需要的字段，并返回新增或更新的字段。

## 各 Agent 的职责

1. `ResumeAgent`：解析简历并提取结构化画像；
2. `JobAgent`：识别岗位、必备技能、加分技能和职责；
3. `RAGAgent`：从本地知识库检索相关求职知识；
4. `MatchAgent`：计算可解释匹配分数和技能证据；
5. `ResumeCoachAgent`：提供不编造经历的修改建议；
6. `InterviewAgent`：根据已匹配和缺失技能生成问题；
7. `LLMAgent`：配置 API 时提供个性化增强；
8. `ReportAgent`：汇总报告和执行轨迹。

## 评分为什么不是直接问大模型

如果让模型直接给 0～100 分，同一份输入多次执行可能波动，而且难以解释。当前版本用固定权重计算必备技能、加分技能、关键词和项目证据，保证结果可复现。模型只负责对规则结果做语言层面的个性化增强，不修改基础分数。

## RAG 是怎么实现的

当前知识库按照 Markdown 二级标题切分文档，使用中英文词元重叠计算相关度，返回最相关的三个片段。这是一个不需要下载 Embedding 模型的词法基线。升级方案是使用 Embedding + Chroma/FAISS，并分别评估检索召回率和最终建议的忠实度。

## 如何防止编造简历

- 匹配阶段只认简历原文中能找到的技能；
- 报告给出对应证据行；
- 建议模板使用“待填写真实结果”的占位符；
- 大模型系统提示明确禁止编造；
- 发送给模型的数据不包括联系方式；
- 最终仍提醒用户人工检查。

## 异常如何处理

- 文件类型、文件大小和文本长度都进行校验；
- 扫描 PDF 提取不到文本时给出 OCR 提示；
- API 未配置时走 Demo 分支；
- API 调用失败时捕获异常、记录警告并降级；
- SQLite 每次操作使用独立连接，避免页面并发复用同一连接；
- Pydantic 校验节点输出和 API 数据。

## 当前不足与升级方向

- 规则技能词典对同义表达的覆盖有限，可以加入 Embedding 匹配；
- 轻量 RAG 只是基线，可以升级为向量数据库；
- 还没有真实招聘数据标注集，可以采集 50～100 份脱敏 JD 做评测；
- 对外部署需要登录、权限、审计、文件扫描和数据删除；
- 可以加入 LangSmith 追踪和人工评分，比较不同提示词与模型。

## 面试现场演示顺序

1. 双击 `run_ui.bat`；
2. 点击“载入示例”；
3. 运行分析并先展示综合分数；
4. 展示技能证据和风险提示，强调可解释性；
5. 展开 JSON，说明 Pydantic 结构化输出；
6. 展示 Agent 执行轨迹，解释 LangGraph；
7. 保存投递记录并打开投递管理页；
8. 最后主动说明当前限制和升级路线。
