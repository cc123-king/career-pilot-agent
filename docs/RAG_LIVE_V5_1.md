## 定位到的代码问题与修复

复核阶段是独立模型请求，却只描述“与首次核验相同的 JSON”，没有提供完整类型示例。真实模型在 10 道题的复核中把 evidence 输出为对象或 null，违反所需数组契约；原文校验按设计拒绝了这些响应。

v5.1 让复核请求独立携带完整规则、可回答与不可回答的 JSON 示例，并明确 evidence 必须为数组。没有通过类型转换或降低原文约束接受坏响应。同时，界面返回语区分“核验格式/原文校验失败”和“资料不足”，避免混淆原因。评测新增可将向量请求上限硬设为 0 的选项，用原向量缓存完成本次复测。
