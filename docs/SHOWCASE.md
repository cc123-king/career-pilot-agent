# CareerPilot 三分钟演示

固定样例均为虚构，不需要模型密钥。先在项目根目录执行 `python scripts/run_showcase.py`，生成 `outputs/showcase/summary.json`、`report.md`、`draft.md` 和本机历史数据库。

| 时间 | 操作 | 讲解重点 |
|---|---|---|
| 0:00–0:25 | 展示 README 架构与固定输入 | 7个确定的LangGraph节点；建议、匹配和面试问题按规则生成 |
| 0:25–1:00 | 打开“文档核对与历史”，上传 examples/resume.txt，粘贴 examples/job.md；选择规则、关键词 | 原文定位；Fast API/FastAPI明确别名；不改变证据原文 |
| 1:00–1:35 | 只确认一项岗位要求，保存 | 其余待核实，暂停评分；不让遗漏项悄悄消失 |
| 1:35–2:10 | 确认其余要求，查看报告 | 固定样例100分；显示权重、来源、技能缺口及核对范围 |
| 2:10–2:40 | 勾选简历事实、生成草稿，按编号恢复 | SQLite恢复确认状态、检索配置与草稿 |
| 2:40–3:00 | 展示测试和一个限制 | 407项离线回归；来源能追溯不等于经历真实性已核实 |

静态结果见 [固定样例结果](examples/showcase-result.json)。结构化模型模式会发送简历文本和JD至配置的服务，独立于以上离线演示；混合检索需Embedding配置，不把离线关键词指标称为语义效果。

真实问答的初评、失败题复测及未解决问题见 [v5.1报告](RAG_LIVE_V5_1.md)，不要将初评与复测拼成整体准确率。
