# CareerPilot 项目描述与面试要点

面向简历和岗位要求核对，使用Python、LangGraph、FastAPI与Gradio构建七节点分析流程，支持多格式提取、OCR来源追踪、岗位要求确认、技能覆盖、历史草稿和报告导出。

可使用的项目描述：

- 使用Pydantic约束结构化数据，将简历解析、岗位要求核对、检索与报告组织为七节点流程；保存来源证据和确认状态，待核实要求暂停评分，分数表示确认范围内的技能覆盖。
- 实现关键词与服务端Embedding召回、加权RRF和相邻分块窗口；对有引用候选回答实施逐字原文、数值和原问题覆盖检查，分析误拒与错误放行。
- 建立71题回归与技术文档评测：已知35题中19道可回答完成、16道无答案正常拒答；36道技术题22/24完成、11/12正常拒答，另1负例因不一致被拦截。当前助手还标出3条展示回答的引用或条件问题。

不能把固定工作流说成七个自主规划的LLM Agent；不能把完成率写成事实准确率、通用100%或独立人工评测。两套Windows依赖环境各443项离线测试通过，Linux结果以Actions为准。候选人需能解释自己的实际参与、实现与局限。
